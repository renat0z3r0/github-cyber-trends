## English

A daily curated digest of **new, growing or actively maintained open-source cybersecurity repositories**, organised into 15 fixed categories: Malware Analysis, SOC Automation, Incident Response, Compliance / GRC, AI for Cybersecurity, Reverse Engineering, Fuzzing, Threat Intelligence, Detection Engineering / SIEM, Penetration Testing, Cloud Security / DevSecOps, Vulnerability Research, Red Team / C2, OSINT, DFIR / Forensics.

**Selection rules**
- no archived or stale repositories
- no exploits, payloads, vulnerability PoCs or exploit aggregators
- no star-farmed lures and no off-topic projects
- no duplicates of repositories already listed in earlier digests

Sparse categories are kept visible and tagged *(few valid results today)*.

## Top picks today
- [ANSSI-FR/ADTimeline](https://github.com/ANSSI-FR/ADTimeline)
  - ANSSI's AD timeline, updated today, rebuilds what changed in Active Directory from replication metadata, which is gold for a post-compromise investigation.
- [lemonadesaltbagel/veil](https://github.com/lemonadesaltbagel/veil)
  - A local proxy that pseudonymizes PII and secrets before they reach AI coding agents, tackling a very real data-leakage risk.
- [limbowatch/limbowatch](https://github.com/limbowatch/limbowatch)
  - It surfaces advisories already published by maintainers but not yet in the GitHub Advisory Database, the vulnerabilities your scanner cannot see yet.

## Italiano

Digest quotidiano e curato di repository **open source di cybersecurity** nuovi, in crescita o attivamente mantenuti, ripartiti in 15 categorie fisse: Malware Analysis, SOC Automation, Incident Response, Compliance / GRC, AI for Cybersecurity, Reverse Engineering, Fuzzing, Threat Intelligence, Detection Engineering / SIEM, Penetration Testing, Cloud Security / DevSecOps, Vulnerability Research, Red Team / C2, OSINT, DFIR / Forensics.

**Criteri di selezione**
- niente repository archiviati o fermi da tempo
- niente exploit, payload, PoC di vulnerabilità o aggregatori di exploit
- niente lure con stelle gonfiate e niente progetti fuori tema
- niente doppioni rispetto ai digest precedenti

Le categorie con pochi risultati validi restano visibili e sono segnalate con *(pochi risultati validi oggi)*.
