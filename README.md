## English

A daily curated digest of **new, growing or actively maintained open-source cybersecurity repositories**, organised into 15 fixed categories: Malware Analysis, SOC Automation, Incident Response, Compliance / GRC, AI for Cybersecurity, Reverse Engineering, Fuzzing, Threat Intelligence, Detection Engineering / SIEM, Penetration Testing, Cloud Security / DevSecOps, Vulnerability Research, Red Team / C2, OSINT, DFIR / Forensics.

**Selection rules**
- no archived or stale repositories
- no exploits, payloads, vulnerability PoCs or exploit aggregators
- no star-farmed lures and no off-topic projects
- no duplicates of repositories already listed in earlier digests

Sparse categories are kept visible and tagged *(few valid results today)*.

## Top picks today
- [sashiko-dev/sashiko](https://github.com/sashiko-dev/sashiko)
  - Already at about 1.5k stars and backed by the Linux Foundation, it is an agentic code-review system built for the Linux kernel and other critical systems software.
- [BARGHEST-ngo/MESHadb](https://github.com/BARGHEST-ngo/MESHadb)
  - Builds an encrypted peer-to-peer mesh so analysts can run remote mobile forensics (ADB, MVT, AndroidQF) as if the device were local.
- [njuj/unmask](https://github.com/njuj/unmask)
  - Follows the delivery chain down to njRAT/XWorm and extracts C2 and config without ever running the sample.
